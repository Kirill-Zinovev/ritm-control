# RITM — производственный кабинет

React + TypeScript + Vite. Интерфейс по согласованным макетам: обзор, сборщики, печать, производство, склад, поставки и источники данных.

## Что уже реализовано

- Периоды день/неделя/месяц, поиск, сортировка, страницы таблиц.
- Коэффициент сборщика и вклад операций, цель ≥ 1, отдельный учёт выходных/неизвестных данных.
- М² сотрудников по уникальным завершённым рулонам, разбивка по участкам.
- Карточки поставок, план и факт по этапам, CSV состава, резерв свободного товара.
- CSV UTF-8 с сопоставлением столбцов, предварительным просмотром и строгой проверкой. Демо-данные при импорте не смешиваются с реальными.

## Подключение реальных данных

Вкладка «Источники данных» позволяет сохранить ссылки на Google Sheets и уже сейчас загрузить подготовленные CSV. Ссылки сами по себе **не подключают** Google Sheets. Для автоматического чтения следующим этапом нужны серверный доступ к таблицам, сопоставление листов/столбцов, сверка итогов и история изменений.

Исходные таблицы не изменяются. Загруженные снимки и реальные карточки хранятся в этом браузере. Нет совместной базы, входа пользователей или синхронизации между устройствами. Резерв в прототипе не изменяет складскую систему. Импорт сборки принимает исходные операции, а не повторно сводные суммы FBO. Для импорта печати выгружаются **только завершённые рулоны**, площадь уже должна быть рассчитана корректно. Для среднего коэффициента за рабочий день нужны выходы на смену; CSV операций их не заменяет.

## Разработка

Node 22+.

```sh
npm install
npm run dev
```

## Проверки

```sh
npm run typecheck
npm run test:domain
npm run test:sites
npm run build
npm run format:check
```

Браузерная визуальная проверка сейчас заблокирована: в сессии недоступны встроенный браузер и Chrome. Отчёт `design-qa.md` отражает это ограничение, а не подтверждает визуальную готовность.
