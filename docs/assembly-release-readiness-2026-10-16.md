# RITM Assembly release readiness · 2026-10-16

## Состояние

Локальный редизайн и генератор коробов подготовлены и опубликованы в основном Apps Script проекте владельца. Обновлено существующее развёртывание с версии 9 на версию 10; прежняя ссылка сохранена локально. Google Sheets и WorkLog не изменялись, Windows-агент не перезапускался.

## Подготовленные изменения

- `apps-script/assembly/Index.html` — компактная таблица, боковая навигация, карточки для телефона, поиск и раскрытие на клиенте, единая форма записи работы.
- `apps-script/assembly/Code.gs` — существующий Apps Script backend, пакетное чтение, ленивые фото, сохранение WorkLog по idempotencyKey и частичное обновление прогресса.
- `.clasp.json` указывает на проверенный project ID и `apps-script/assembly`; манифест `appsscript.json` перенесён из резервной копии и семантически совпадает с исходным.
- Короба: просмотр, создание и размещение через существующие `Cartons`/`CartonContents`; сервер повторно проверяет поставку, остаток, вместимость, статус и ключ повтора. Новый короб хранит стабильный `shipmentId` в дополнительной крайней колонке `Cartons`, не вставляя строки. Проверки показывают, что старые значения остаются на месте.
- `scripts/assembly-ui-preview.mjs` — локальный просмотр с синтетическим RPC и SVG-картинками; он не является отдельным опубликованным приложением.

## Проверки

- 38 тестов Assembly прошли, включая изоляцию поставок, сохранение истории, повторы, тайм-ауты, коробовые ограничения и смену названия поставки.
- Синтетическая нагрузка на 5/10/20/30 клиентов прошла: 0 потерянных записей, 0 дублей, 0 переполнений тестового короба. Метрики и задержки отражают только локальный mock, а не Google Apps Script.
- Domain: 18 тестов; Sites/printing: 29; Intelligence: 294; TypeScript typecheck и production build прошли. Build оставил предупреждение о крупном frontend-бандле.
- Локальный браузер проверен при 375 и 390 px: переключение поставки, поиск, раскрытие, форма работы, изменение прогресса одной позиции, создание короба и размещение на синтетических данных. Фото в preview синтетические; настоящий телефон и реальные фото не проверялись.

## Резервные копии

Резервные копии проверены в закрытом хранилище; ссылки и идентификаторы оставлены в локальной конфигурации.

- Исходники Apps Script и манифест: закрытая резервная копия сверена по SHA-256.
- Таблица приложения: резервная копия сверена; структура и важные листы совпали, кроме временной метки синхронизации в колонке U.
- Источник печати: резервная копия сверена с рабочей книгой; ссылка хранится локально.
- Каталог: резервная копия сверена, включая видимые и скрытые вкладки; ссылка хранится локально.
- Настройки проекта, Script Properties, развёртывания и триггеры сохранены в закрытой резервной копии; ссылка хранится локально.

### Подтверждение основной цели и совместимости

Ссылка `[закрытая ссылка на Web App]` теперь обслуживается существующим deployment версии 10. Его ID и URL не изменились; до обновления у него были режим запуска от имени владельца и доступ «Все». После публикации страница открылась по прежней ссылке и загрузила живую поставку «OZON МОСКВА 10_10», 147 позиций, из листа печатников. Код связан с источником `OZON РУЛОННАЯ ПЕЧАТЬ` и каталогом FBO. Проект и отдельная старая таблица `Shipments` имеют слово «тестовый», но это не тот поток, из которого строится рабочий экран.

- В одной таблице сохранены старые строки `TEST ONLY`: одна в `Shipments`, 12 строк старого `Items` и 79 тестовых событий WorkLog. Текущий код Web App не смешивает их с рабочими поставками: выбор строится по живым `ritm.assembly.supply.*` Script Properties и маркированным листам зеркала.
- WorkLog содержит 85 событий всего: 79 с тестовым ID и 6 событий с живыми ID `RITM-ROLL-*`. Новая версия сохраняет этот журнал и фильтрует операции по `shipmentId`, `directionId` и `positionId`; заголовок `idempotencyKey` присутствует.
- Текущий лист-зеркало «OZON МОСКВА 10_10» содержит 147 товаров плюс заголовок. Его значения A:T совпали с резервной копией; колонка U «Синхронизировано» естественно обновляется минутным триггером. `WorkLog`, `Shipments`, `Items`, `Employees`, `OperationNorms`, `Cartons`, `CartonContents` и `Metadata` сверены с копией по значениям и количеству строк.
- Реальная схема совместима: `Employees` имеет `employeeId/Имя/Активен`; `OperationNorms` — нормы по позициям и операциям; `CartonContents` уже содержит `shipmentId`; `Cartons` содержит 10 старых столбцов, новая версия добавит `shipmentId` только справа, без вставки строк или сдвига старых колонок. В обеих таблицах коробов сейчас только заголовки.
- В Apps Script настроен один владельческий триггер `syncRitmSupplies` раз в минуту; последнее отображённое выполнение — 16 окт. 2026, 09:16:35, частота ошибок 0,3%. Предыдущая версия 9 сохранена в истории проекта и может быть возвращена обновлением того же deployment; другой активный deployment версии 1 имеет доступ «Только у меня» и на публичную ссылку не влияет.

Google хранит Script Properties отдельно для каждого script ID ([официальная документация](https://developers.google.com/apps-script/guides/properties)). Все 6 текущих свойств и настройки проекта сохранены в закрытой копии. Обновление существующего deployment не меняет Script ID и не заменяет эти свойства.

- Версия 10 опубликована в исходный deployment ID `AKfycbwbD...`; `clasp deployments` показывает прежний ID на версии 10.
- Через прежний URL проверено открытие живой поставки, список из 147 позиций и отображение прогресса из WorkLog.
- Раскрытие артикула работает; показана команда из одного сотрудника и её операции. Поиск по `KS0002.A7665` сократил список до одной позиции; очистка поиска восстановила 147.

- В проверенных строках каталога отображается «Нет фото»; наличие и ленивую загрузку реальных фотографий подтвердить не удалось.
- Рабочие записи WorkLog, новые короба и размещения не создавались. Настоящий телефон отдельно не проверялся.

## Ограничения после публикации

1. Реальное сохранение работы не тестировалось: производственную операцию нельзя создавать как тестовую. Для проверки записи нужен отдельный реальный ввод с разрешением пользователя.
2. В проверенных живых строках у части товаров нет фото в каталоге. Ленивая загрузка проверена только на синтетических изображениях локального preview; реальные фото отдельно не проверены.
3. Настоящий телефон после публикации не проверялся. Локальная адаптивность проверена при 375 и 390 px.

Проверочный список: 38/38 Assembly, 1/1 синтетический нагрузочный сценарий на 5/10/20/30 клиентов, 18/18 domain, 29/29 Sites/printing, 294/294 Intelligence; typecheck и production build прошли. Локальный preview проверен при 375 и 390 px. Синтетическая нагрузка не доказывает производительность Apps Script под реальными пользователями.

Публикация выполнена в существующее развёртывание с сохранением URL. Рабочие записи не создавались; основной Windows-агент не перезапускался.
