# Глубокая проверка ожидания операций — 17.11.2026

Проверены пути одиночного и пакетного переноса, создание/добавление поставок, повторные запросы, отмена, блокировки, восстановление после неопределённого ответа, складские операции и общая перезагрузка сводки.

Исправления:
- GET состояния переноса/пакета читает только нужный вид операции и конкретный ID, если он задан. Ранее читались все cloud_state, операции, предварительные расчёты и события.
- Перед записью производственного Sheets-запроса устранён дублирующий checkpoint. Остался один обязательный guard в защищённом fetch до отправки. Количество guard/checkpoint на запрос: 2 → 1. Ошибка guard сохраняет beforeExternalWrite и блокирует отправку.
- После подтверждённого одиночного или завершённого пакетного переноса окно освобождается до окончания обновления общей сводки. Подтверждение переноса не подменяется оптимистическим результатом.

Не изменены: порядок физических записей, повторная проверка назначения, блокировка исходного участка, идентификатор повторного запроса, восстановление неопределённой записи, формулы, Google Sheets и старый Assembly.

Проверки: TypeScript и production build. Серверные регрессионные тесты, включая переносы между участками, пакеты, потерю ответа, отмену, склад, поставки и права. Отдельный тест доказывает один guard и отсутствие HTTP-записи при его ошибке. Браузерный тест реального компонента с изолированным API: один POST, подтверждённое завершение, окно закрывается при намеренно незавершающемся обновлении сводки.

Предел доказательства: производственный перенос товаров для замера не создавался. Не заявляем конкретное ускорение всей операции в секундах: сетевое время Google Sheets / Apps Script остаётся внешней зависимостью. Ограниченный журнал сервера не содержит достаточной серии фактических переносов для честного сравнения до/после.
