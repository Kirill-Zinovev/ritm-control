## Архитектура и работающие функции

Существующий агент дополнен модулем Table Doctor. Реестр → read-only Google API/локальная фикстура → детерминированные проверки → постоянная SQLite → авторизованный AI Center → очередь Telegram. LLM для этих проверок не нужен, вызовов AI API нет.

Работают проверки наличия формулы, замены числом, утверждённого шаблона и исключений, недействительной ссылки, ошибки вычисления, проверяемого результата, структуры листа, UID, числа/даты и согласованного рабочего интервала.

Правила pending формируют только «Требует проверки». Проверенные эталонные снимки применимы только к той же версии правила. Отличие от соседней строки не является диагнозом.

Локальные заявки и игнорирование требуют авторизации владельца и не меняют производственные документы. Прежние инциденты не закрываются при недоступности API или неполной проверке структуры.

## Настоящие данные и необходимые настройки

Реальный мониторинг CSV FBO и «Журнал выпуска», API сборки/печати и HTML работает. Последняя проверка: FBO 486 записей, печать 48 валидных записей; источники и API доступны.

Фоновые проверки **исходных формул Google** пока не выполняются: требуется сервисный аккаунт, роль «Читатель» на разрешённых документах и локальный путь RITM_GOOGLE_CREDENTIALS_FILE. Подключение Google в интерфейсе ChatGPT не предоставляет автоматически ключ для самостоятельного Windows-процесса.

Нужно утвердить точные шаблоны IMPORTRANGE/итога FBO и площади J, разрешённые ссылки, диапазоны и исключения. Шаблоны-кандидаты уже внесены в реестр. Для связанных таблиц сборки добавляются отдельные документы.

Telegram: отдельные bot token/chat_id через DPAPI-настройку Windows. Пока «Не настроено»; транспорт и очередь протестированы без реальных сообщений.

## Ограничения и следующий этап

Реальный Google OAuth и реальные Telegram-отправки не проверены без внешних секретов. Формульные правила требуют утверждения; диапазоны ограничены реестром. Анализ произвольной динамической формулы, всего графа IMPORTRANGE и полная междокументная сверка не реализованы.

Исправление Sheets, откат, зарплаты/нормы, AI-чат и production-деплой отключены. Реестр и хранилище расширяемы; выполняющий механизм исправлений требует отдельного этапа с повторным чтением, проверкой владельца и версии ячейки, точечной записью, проверкой результата и откатом.

GPT Sites можно обновить с текущим UI и честным отключённым состоянием агента. Для общего онлайн AI Center потребуется защищённый серверный backend. Локальный API наружу не публиковался.
