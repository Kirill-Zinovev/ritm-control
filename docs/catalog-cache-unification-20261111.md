# Единый источник каталога производственных книг

Область: OZON РУЛОННАЯ ПЕЧАТЬ и OZON БОКС. Исходный каталог БАЗА FBO и журналы работы не редактируются.

## Соответствие полей

В обеих книгах `Cache FBO` напрямую импортирует `OZON!A2:R` из БАЗА FBO. Ключ поиска — нормализованный артикул в B. Количество листов — F, размер — G, папка печати — J, станок — O. Кратность рулонной печати находится в Q (индекс 16 относительно B). Столбец R, формально предназначенный для Xerox, содержит сохранённые ошибки, поэтому не используется как замена рабочей кратности бокса.

`БДО` в книге рулонной печати импортировала первые пятнадцать столбцов того же каталога. Потребители переводятся на `Cache FBO` без изменения остальных частей формулы, включая существующий разрешённый fallback для технических свойств товара. Новый writer также использует `Cache FBO`.

Старый `Cache` рулонной печати импортировал другой справочник с иной схемой. Его ссылки переводятся только по подтверждённому назначению заголовка: станок, кратность или наличие макета. `Cache` бокса импортировал таблицу макетов; его кратность Xerox переводится на тот же исходный столбец Q через существующий `_RITM_МАКЕТЫ`. Этот импорт расширяется с B:L до B:Q, первые одиннадцать столбцов остаются на месте, кратность Xerox оказывается в P (индекс 16 относительно A).

Наличие макета продолжает проверяться по `_RITM_МАКЕТЫ`, включая отметку готовности резки под станок и проверку доступности источника. Этот справочник имеет другую семантику и не объединяется с товарным каталогом. `_RITM_WB_SOURCE` также сохраняется.

## Предохранители миграции

- Полная инвентаризация формул всех листов, в том числе скрытых; содержимое исходных клеток сохраняется вне Git.
- Изменяются только распознанные формулы, соответствующие заголовкам. Ручные значения остаются на месте. Неизвестная схема останавливает подготовку.
- Перед записью повторно читаются точные диапазоны; изменившаяся формула не перезаписывается. Повторный запуск распознаёт уже применённый результат.
- Запись ограничена `userEnteredValue`; форматы, проверки данных, фильтры, планы, UID и рабочие журналы не затрагиваются.
- Отключение старого внешнего импорта допускается только после полной повторной проверки отсутствия зависимостей. Вкладки не удаляются; исходная формула импорта сохранена для отката.
- После записи проверяются все изменённые формулы, действующие артикулы и сохранность остальных исходных значений и формул. Новые операции сотрудников во время сверки учитываются отдельно.

## Проверки кода

Отдельные тесты проверяют разные индексы кратности рулонов и Xerox, заголовки, неизвестные формулы, локальные строки и абсолютные ссылки, сохранение ручных значений и отсутствие изменения планов. Сценарии создания, добавления и переноса проверяют использование общего каталога новыми строками.
