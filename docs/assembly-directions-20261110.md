# Assembly: направления, готовые товары и панель коробов

Дата проверки: 10.11.2026. Опубликована версия Apps Script 98 на существующее развёртывание Assembly.

## Реализовано

- Навигация по маркетплейсу, городу и подтверждённому магазину каталога. Неоднозначный магазин или неизвестный город остаётся отдельной исходной поставкой.
- Исходные задания доступны в раскрывающемся списке и подписаны у товаров. Одинаковый SKU из разных исходных заданий сохраняет самостоятельный positionId, план и журнал; это разные строки, а не объединённая производственная запись.
- «В работе» по умолчанию; «Готовые» и «Все» сохраняют доступ к выполненным позициям. Готовность требует подтверждённой упаковки и распределения всей упаковки по коробам, включая излишек на склад.
- Прямая запись работы из строки. В форме — сотрудник, операция, количество, остаток, результат и раскрываемые нормы.
- Панель коробов: выбор товара текущей группы с исходным заданием, общие короба направления, состав, остаток, заполнение, «Все доступные», закреплённая кнопка сохранения. Короба другого подтверждённого магазина исключены из подходящих; существующие распределения и старые номера остаются доступны для просмотра.
- Сохранены исходные API, idempotencyKey, проверки магазина/вместимости/блокировок, этикетки, комментарии и задачи, журнал исправлений, излишки на склад и история коробов.
- Группировка — представление. Производственные листы не объединяются, ID и события не переписываются. Поддельная работа в рабочие журналы не добавлялась.

## Изменённые файлы

- apps-script/assembly-live/Code.gs — индекс направлений, подтверждённое общее распределение с учётом склада, номер магазина в публичной карточке короба.
- apps-script/assembly-live/Index.html — новая навигация, вкладки, формы и панель коробов, защита поздних чтений и исходных ID.
- apps-script/assembly/Code.gs и Index.html — поддерживаемая копия; конфигурация ID через Script Properties сохранена.
- apps-script/assembly/appsscript.json — синхронизирован с действующей конфигурацией скрипта.
- scripts/assembly-ui-preview.mjs — изолированный локальный стенд с группами и актуальным контрактом ответов; без Google-доступа.
- tests/assembly-supply-sync.test.mjs — новые проверки группировки, готовности, ID, блокировок, позднего чтения, повторного запроса и выбора магазина. Старые ожидания приведены к уже опубликованному контракту версии 96 (общие короба, скрытая история, параллельный bootstrap).
- DESIGN.md и UX-CONTRACT.md — согласованные визуальные и поведенческие решения.

## Границы и замечания

- Сохранение и повторные запросы проверены на изолированных данных. В рабочем приложении выполнялись только чтение и навигация.
- Общий статический дизайн-аудит репозитория вернул 17 прежних замечаний в других компонентах главного RITM. Эти файлы не менялись; массовые исправления вне Assembly не выполнялись.
- При проверке старой «OZON МОСКВА 10_10» источник показал прежнее предупреждение «Источник теперь связан с общей поставкой; требуется сверка». Сохранённый состав оставлен без миграций; задача дизайна не меняет эту связь.
- Холодное чтение Google Apps Script всё ещё зависит от Google Sheets; сгруппированные задания читаются по запросу, с кэшем и ограничением фоновой очереди. Обещание мгновенной загрузки без измерений не делается.
- Для главного RITM подготовлен только отдельный визуальный макет «Сборка по направлениям» с примером данных. Его внедрение не выполнялось.
