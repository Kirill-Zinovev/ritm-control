# Доставка исходников на GitHub

Репозиторий ritm-control хранит основной РИТМ в корне, новую Сборку в assembly-v2 и Печать в printing. Файл sources.json указывает коммиты Sites, из которых собрана ветка main на GitHub.

Установите обработчик для каждого рабочего клона Sites командой ниже. Требуются Node.js, Git и действующий вход в GitHub через Git Credential Manager.

    node github-delivery/mirror.mjs install "<путь к клону Sites>"

После проверок сделайте обычный коммит в клоне Sites. Обработчик отправит его исходники в main и сверит SHA на GitHub. При повторной отправке тех же исходников коммит на GitHub не создаётся.

    node github-delivery/mirror.mjs sync "<путь к клону Sites>"

Команда plan показывает объём изменений перед отправкой. Команда sync принимает несколько путей. Обе читают файлы указанного коммита. Скрипт блокирует выгрузки баз, архивы и известные форматы ключей. Токены вебхуков в тестовых примерах заменяются синтетическими значениями.

Если GitHub отклонил отправку, локальный коммит сохранится. Восстановите доступ и повторите sync. Публикация в Sites выполняется штатным отдельным шагом.
